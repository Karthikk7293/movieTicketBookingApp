# movieTicketBookingApp

Early movie-ticket booking website prototype using Express, MongoDB, and Handlebars, with user and admin routes.

## Configuration

Connected features require MongoDB. Review the corresponding configuration and integration modules before running the app.

## Run locally

Install Node.js and the package manager used below. Run each command block from the repository root; separate frontend/backend processes use separate terminals.

Root application:

```sh
npm install
npm run start
```
